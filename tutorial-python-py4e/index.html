3. Estructuras Condicionales

Los programas pueden tomar decisiones. Un ejercicio clásico de PY4E es calcular el pago de un trabajador que incluye horas extras.

Si trabaja más de 40 horas, recibe un pago 1.5 veces mayor a la tarifa habitual por esas horas adicionales.

horas = 45
tarifa = 10.0

if horas > 40:
    pago_regular = 40 * tarifa
    pago_extra = (horas - 40) * (tarifa * 1.5)
    pago_total = pago_regular + pago_extra
else:
    pago_total = horas * tarifa

print("El pago total es:", pago_total)

4. Funciones (def y return)

Para evitar repetir código y hacerlo más organizado, agrupamos bloques de instrucciones en funciones mediante la palabra clave def. Las funciones pueden devolver un resultado utilizando return.

def calcular_pago(horas, tarifa):
    if horas > 40:
        reg = 40 * tarifa
        ext = (horas - 40) * (tarifa * 1.5)
        total = reg + ext
    else:
        total = horas * tarifa
    return total

salario_juan = calcular_pago(45, 10.0)
print("Salario calculado desde función:", salario_juan)

5. Bucles e Iteraciones

Los bucles nos permiten repetir tareas sobre conjuntos de datos. El bucle for se usa habitualmente para recorrer los elementos de una lista.

nombres = ['Joseph', 'Glenn', 'Sally']

for amigo in nombres:
    print("Feliz Año Nuevo:", amigo)
print("¡Iteración completada!\n")

# Buscar el número mayor en una lista
mayor_encontrado = -1
for numero in [9, 41, 12, 3, 74, 15]:
    if numero > mayor_encontrado:
        mayor_encontrado = numero
print("El número mayor es:", mayor_encontrado)
